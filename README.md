# To Create a bookmarklet:

Step 2. Copy The Code Of Any .js File

Step 3. Replace the URL of the bookmark you just added with the code you just copied

Step 4. Go to a tab(can't be google related) and open the bookmark you just edited to run the bookmarklet

Step 5. Refresh the page to turn off bookmarklet
